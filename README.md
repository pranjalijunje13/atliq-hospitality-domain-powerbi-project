# 🏨 Hospitality Domain Data Analytics Project

An end-to-end **Power BI** data analytics project focused on the **Hospitality industry**.
The dashboard transforms raw booking and revenue data into actionable business insights that support strategic decision-making for hotel management.

## 📌 Project Overview

The **Hospitality Analytics Dashboard** enables stakeholders to:

- Track overall revenue performance
- Monitor pricing and occupancy trends
- Evaluate property-level KPIs
- Compare weekday vs weekend performance
- Analyze booking platform effectiveness
- Identify high-performing and underperforming cities

This project demonstrates a real-world business intelligence implementation using **Power BI, SQL, Excel, and DAX**.

## 📊 Key Performance Indicators (KPIs)

| KPI | Description |
|-----|-------------|
| **Revenue** | Total revenue generated |
| **RevPAR** | Revenue per Available Room |
| **ADR** | Average Daily Rate |
| **Occupancy %** | Percentage of rooms occupied |
| **Realisation %** | Revenue realised after bookings |
| **DSRN** | Daily Sellable Room Nights |
| **DBRN** | Daily Booked Room Nights |
| **DURN** | Daily Utilized Room Nights |

## 🧠 Key Business Insights

1. **Business** category contributes a larger share of total revenue than the **Luxury** segment.
2. **Weekend occupancy** is higher than weekday occupancy.
3. Certain cities achieve **strong RevPAR despite moderate occupancy**, indicating effective pricing strategies.
4. **Direct booking platforms** show higher realisation percentages.
5. Weekly trend analysis reveals clear **seasonality patterns**.
6. **Cancellation %** directly impacts realisation performance.
