🏨The Hospitality Domain Data Analytics Project
An end-to-end Power BI Data Analytics Project focused on the Hospitality industry.
This dashboard transforms raw booking and revenue data into actionable business insights that support strategic decision-making for hotel management.

📌 Project Overview
The Hospitality Analytics Dashboard enables stakeholders to:

Track overall revenue performance
Monitor pricing and occupancy trends
Evaluate property-level KPIs
Compare weekday vs weekend performance
Analyze booking platform effectiveness
Identify high-performing and underperforming cities
This project demonstrates real-world business intelligence implementation using Power BI, SQL, Excel, and DAX.

🏨 Business Domain
Hospitality Industry (Hotel Revenue Management & Performance Analytics)

🎯 Business Objectives
Monitor overall revenue and core KPIs
Analyze occupancy and ADR trends across cities and properties
Compare weekend vs weekday performance patterns
Evaluate booking platform contributions
Improve realization and reduce cancellations
Enable data-driven pricing and operational strategies
🛠 Tools & Technologies Used
Power BI – Dashboard development & visualization
Excel – Data preprocessing
SQL – Data extraction & transformation
DAX – KPI calculations & measures
Data Modeling – Relationship building & star schema
📊 Key Performance Indicators (KPIs)
KPI	Description

📂 Dataset
The dataset used for this project is available inside the Dataset folder.
It includes booking records, property details, room categories, and performance metrics.

🧠 Key Business Insights Generated
Business category contributes a larger share of total revenue compared to the luxury segment.
Weekend occupancy rates are higher than weekday occupancy.
Certain cities achieve strong RevPAR despite moderate occupancy levels, indicating effective pricing strategies.
Direct booking platforms demonstrate higher realization percentages.
Weekly trend analysis reveals clear seasonality patterns.
Cancellation percentage directly impacts realization performance.
